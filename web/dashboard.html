Owner connection

Membership and roles are checked automatically through Discord on every protected request. Configure agencies in web/access.json and restart the service. No bot is required for this login flow.

First setup · server owner
  1. Create an application in the Discord Developer Portal. Copy its application ID.
  2. In Discord settings enable Developer Mode. Copy your server ID, your owner user ID, and the role IDs for each agency.
  3. On the website host, open the GitHub project folder and run npm run setup:web. Enter those IDs and your public HTTPS portal address.
  4. Register the exact /auth/discord/callback URL printed by the wizard in your application's OAuth2 redirects.
  5. Put the client secret in the host's .env file. Never enter it in this panel or commit it to GitHub.
  6. Run npm run start:web. Configure HTTPS to proxy to loopback port 8790 while preserving the public Host header.
  7. Sign in with Discord as the configured owner. Test a mapped officer, dispatcher and an unmapped member to verify access.
  8. Install the FiveM resource separately. Login does not yet connect camera feeds or recording storage.

No bot installation is required for login. The owner completes application creation and secret setup in Discord; membership and roles are then checked automatically. See web/SETUP.txt for troubleshooting.
